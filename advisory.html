Administrator advisory

KEEP CALM. CHECK YOUR SITE.

Unexpected website changes can be disruptive. These general steps can help administrators investigate safely and recover clean content.

1. Review recent changes

Check recent deployments, content edits, plugins and account activity. Identify when the unexpected changes first appeared.

2. Secure administrator accounts

Change potentially exposed passwords, enable multi-factor authentication and review who has access to the site.

3. Restore from a trusted backup

Compare affected files with a known-good backup and restore clean copies after confirming the source is trustworthy.

4. Contact your hosting provider

Ask the provider to help inspect server logs, unusual file changes and suspicious account activity.

5. Avoid mystery cleanup tools

Do not run unknown scripts or download unverified tools claiming to remove the incident. Use trusted security resources.
